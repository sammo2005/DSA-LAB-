# College Homework

This folder contains C programs prepared for college laboratory and homework practice.

## String Operations

### File
`string_operations.c`

The program demonstrates several common string operations:

- String comparison
- String concatenation
- Finding string length
- Character searching
- Substring searching

The operations are combined into a simple menu-driven program so that each function can be tested separately.

## Compilation

```bash
gcc string_operations.c -o string_operations
