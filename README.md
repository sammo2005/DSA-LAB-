# DSA Lab - Data Structures & Algorithms in C

A collection of **Data Structures and Algorithms** implementations written in **C** for learning, laboratory work, and academic practice.

This repository contains fundamental data structures, common algorithms, searching and sorting techniques, recursion problems, graph representations, and other programming exercises. Each topic is organized into separate folders so that the programs can be studied and tested independently.

---

# 📌 About This Repository

The purpose of this repository is to build a practical understanding of **Data Structures and Algorithms** through C programming.

Instead of only studying the theoretical concepts, this repository focuses on implementing the core logic of different data structures and algorithms from scratch.

The repository is organized by topic, with each folder containing related source files and documentation.
